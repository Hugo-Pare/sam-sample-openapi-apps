# Stock Portfolio API

A sample REST API for managing stock portfolios built with FastAPI and PostgreSQL. This API demonstrates full CRUD operations with automatic OpenAPI 3.0 specification generation.

## Features

- ✅ Full CRUD operations for stocks and portfolio holdings
- ✅ Automatic OpenAPI 3.0 documentation
- ✅ PostgreSQL database with SQLAlchemy ORM
- ✅ Sample data preloaded on startup
- ✅ Portfolio metrics calculation (profit/loss, current value)
- ✅ Input validation with Pydantic
- ✅ Interactive API documentation (Swagger UI & ReDoc)

## Prerequisites

- Python 3.9+
- Docker and Docker Compose
- pip

## Quick Start

### 1. Start the PostgreSQL Database

```bash
podman run -d --name stock-portfolio-db \
  -e POSTGRES_USER=stockuser \
  -e POSTGRES_PASSWORD=stockpass \
  -e POSTGRES_DB=stockportfolio \
  -p 5432:5432 \
  docker.io/library/postgres:15-alpine
```

This will start a PostgreSQL container on port 5432.

### 2. Create Virtual Environment and Install Dependencies

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 3. Run the API Server

**Default port (8000):**
```bash
# Make sure virtual environment is activated
source .venv/bin/activate
uvicorn app.main:app --reload
```

**Custom port:**
```bash
uvicorn app.main:app --reload --port 3000
```

Or using environment variable:
```bash
PORT=3000 python -m app.main
```

### 4. Access the API

- **API Base URL**: http://localhost:8000
- **Interactive Documentation (Swagger UI)**: http://localhost:8000/docs
- **Alternative Documentation (ReDoc)**: http://localhost:8000/redoc
- **OpenAPI Specification**: http://localhost:8000/openapi.json

## API Endpoints

### General
- `GET /` - API information
- `GET /health` - Health check

### Stocks
- `GET /stocks` - List all stocks (supports pagination and filtering by sector)
- `GET /stocks/{stock_id}` - Get stock by ID
- `GET /stocks/symbol/{symbol}` - Get stock by symbol
- `POST /stocks` - Create new stock
- `PUT /stocks/{stock_id}` - Update stock
- `DELETE /stocks/{stock_id}` - Delete stock

### Portfolio
- `GET /portfolio` - List all portfolio holdings with metrics
- `GET /portfolio/{holding_id}` - Get specific holding with metrics
- `POST /portfolio` - Add stock to portfolio
- `PUT /portfolio/{holding_id}` - Update portfolio holding
- `DELETE /portfolio/{holding_id}` - Remove from portfolio
- `GET /portfolio/summary/total` - Get portfolio summary

## Example Usage

### Get all stocks
```bash
curl http://localhost:8000/stocks
```

### Get a specific stock by symbol
```bash
curl http://localhost:8000/stocks/symbol/AAPL
```

### Create a new stock
```bash
curl -X POST http://localhost:8000/stocks \
  -H "Content-Type: application/json" \
  -d '{
    "symbol": "INTC",
    "company_name": "Intel Corporation",
    "sector": "Technology",
    "current_price": 45.23
  }'
```

### Get portfolio with metrics
```bash
curl http://localhost:8000/portfolio
```

### Add stock to portfolio
```bash
curl -X POST http://localhost:8000/portfolio \
  -H "Content-Type: application/json" \
  -d '{
    "stock_id": 1,
    "shares": 100,
    "purchase_price": 150.00,
    "purchase_date": "2023-01-15",
    "notes": "Long term investment"
  }'
```

### Get portfolio summary
```bash
curl http://localhost:8000/portfolio/summary/total
```

## Database Configuration

The database connection is hardcoded in `app/database.py`:

```
postgresql://stockuser:stockpass@localhost:5432/stockportfolio
```

Database credentials are defined in `docker-compose.yml`.

## Stopping the Application

Stop the API server: Press `Ctrl+C`

**Stop the PostgreSQL container:**
```bash
podman stop stock-portfolio-db
podman rm stock-portfolio-db
```

**To remove all data:**
```bash
podman stop stock-portfolio-db
podman rm stock-portfolio-db
podman volume prune
```

## OpenAPI Specification

This API is fully compliant with OpenAPI 3.0 specification. The specification is automatically generated by FastAPI and includes:

- All endpoint definitions
- Request/response schemas
- Validation rules
- Data types
- Example values

Access the spec at: http://localhost:8000/openapi.json
